# Roadmap

## v0.2 — после первого реального цикла

- Пройти Cloud/real-API/Windows приёмку, зафиксировать usage и практическую стоимость.
- Добавить загрузку только текстовых исходников и метаданных работ, с сохранением source identity и дат.
- Укрепить quality gate на реальных гипотезах и отзывах Виктора; проверка наличия ответов не доказывает качество идеи.
- Добавить выбор материалов для входа по pointers, более точный учёт cache writes и тарифа аккаунта.
- Разделить ART/TATTOO каталожные представления по реальной схеме, не по общему списку типов.
- Добавить контролируемый импорт резервной копии и миграции schema_version.

## v0.3 — продолжительная автономная работа

- Перенести snapshots/artifacts в постоянную базу/объектное хранилище при росте архива.
- Отдельный постоянно работающий worker и надёжная очередь, если нужны строгие времена 24/7.
- Проверить Agents API / session persistence за адаптером без потери текущей файловой памяти.
- Добавить версии решений, фиксацию принятых гипотез и связь с 30-дневными экспериментами.
- Подтверждать смену positioning и цен отдельными действиями Виктора.

Генерация фото/видео, автоматическая публикация, сообщения людям и покупки в roadmap не включены.
