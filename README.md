# Viktor Mir / Ангелис — Streamlit MVP v0.1

Личный творческий офис Виктора Мира: рабочая память, приоритетные задачи, текстовые результаты, журнал и контроль расходов. Цель: рост Viktor Mir как художника и живописца при сохранении татуировки как текущего источника дохода.

Этот вариант использует GitHub + Streamlit по уточнённому запросу Виктора. Оригиналы пяти файлов спецификации сохранены без изменений в `spec/` как исходное задание со старым именем. Рабочие инструкции в `prompts/system.md` и `prompts/daily-report.md` используют новое имя Ангелис.

## Быстрый запуск через интернет

Отдельный проект: приватный репозиторий `Kartinaboy/viktor-mir-angelis`, ветка `main`. Файл запуска `app.py` находится в корне репозитория.

1. Открой [Streamlit Community Cloud](https://share.streamlit.io/) и выбери **Create app** / **Deploy app**.
2. Укажи:

   | Поле | Значение |
   | --- | --- |
   | Repository | `Kartinaboy/viktor-mir-angelis` |
   | Branch | `main` |
   | Main file path | `app.py` |
   | Python | `3.12` |

3. Открой **Advanced settings → Secrets** и вставь шаблон ниже со своими значениями. Если приложение уже создано, используй **Settings → Secrets**.

   ```toml
   OPENAI_API_KEY = "твой-ключ-OpenAI"
   GITHUB_TOKEN = "твой-fine-grained-token"
   GITHUB_REPO = "Kartinaboy/viktor-mir-angelis"
   GITHUB_DATA_BRANCH = "angelis-data"
   APP_PASSWORD = "твой-личный-пароль"
   ANGELIS_STORAGE = "github"
   ```

   Для GitHub token: [создать fine-grained token](https://github.com/settings/personal-access-tokens/new), Resource owner `Kartinaboy`, Only select repositories → `viktor-mir-angelis`, Repository permissions → **Contents: Read and write**. Metadata доступен автоматически. Выбери срок действия, который сможешь своевременно продлевать. Не вставляй ключи в README, Python-файлы, историю Git или переписку.

4. Нажми **Deploy**. Полученную ссылку открывай с компьютера, телефона или планшета. При первом входе введи `APP_PASSWORD`.
5. На TODAY выбери **Dry Run**, нажми **Запустить Ангелис**. Это не вызывает API. Затем нажми **Проверить API**: один короткий запрос Luna, с учётом токенов и стоимости. После успешного теста запускай Normal.

Первое открытие приложения не запускает дорогую работу. Наличие строки API-ключа не означает, что доступ к выбранным моделям уже проверен. Ошибка API сохраняется в Journal, задача возвращается в очередь, STATE не повреждается. Нет автоматического переключения на другую модель при отказе.

## Что хранится постоянно

Отдельная **приватная ветка `angelis-data`** того же репозитория — источник рабочей памяти. Страница браузера и диск Streamlit не являются источником истины.

```text
data/workspace.json          полный атомарный снимок
data/state/STATE.json        компактная память
data/backlog/BACKLOG.csv     приоритетная очередь
data/settings.json          модели, бюджеты, расписание
data/journal/JOURNAL.jsonl   действия, ошибки и решения
data/runs/*.json            запуски и usage
data/strategy/*             стратегия
data/research/*             исследования и ссылки
data/editorial/*            текстовые концепции и черновики
data/decisions/*            проверки и Idea Ledger
data/reports/*              отчёты
```

GitHub сохраняет изменения атомарным Git commit. Обновление ветки разрешено только fast-forward; при конфликте снимок читается заново, изменения другого устройства не затираются. API-ключ, GitHub token и пароль в этих файлах не сохраняются.

Рабочая память продолжается после обновления страницы, перезапуска приложения и перехода на другое устройство. Настройки → **Скачать STATE, BACKLOG, журнал и все файлы** даёт полную резервную копию. История версий остаётся в GitHub.

## Ежедневная работа

- **TODAY:** MONEY NOW / ART CAPITAL, задача по приоритету, свои инструкции, Normal / Dry Run / Deep Strategy, этапы работы.
- **BACKLOG:** создание задачи, критерий готовности, приоритет, пауза через blocked, reject, запуск и review. Статус done разрешён только с файлом и твоим пояснением, как выполнен критерий.
- **STRATEGY / RESEARCH / CONTENT / ART / TATTOO:** текстовые материалы с чтением, raw, metadata и скачиванием. Каталог исходных произведений не выдумывается.
- **JOURNAL:** дата UTC, запуск, модель, роль, ошибки, решения, записанные файлы. Приватные рассуждения модели не запрашиваются и не сохраняются.
- **COSTS:** input/output/cached tokens, модели, поиск, оценка расходов, резерв после обрыва. Это не баланс аккаунта OpenAI.
- **SETTINGS:** модели, reasoning, роли, budgets, web research, часовой пояс, расписание, экспорт.

До появления реальных исходных материалов выводы являются гипотезами и черновиками. Ангелис не фиксирует крупную смену позиционирования, не меняет цены, не удаляет исходники и не публикует от твоего имени.

## Модели и стоимость

Используется официальный Python SDK и **Responses API fallback** через `ResponsesLLM`. Состояние хранится в собственных файлах. `response_id` сохраняется для аудита, но это не Agents `session_id`. Agents API в v0.1 не используется.

| Режим / работа | Модель по умолчанию |
| --- | --- |
| Обычная работа, редактура, отчёты | `gpt-6-sol` |
| Архив, обслуживание, API-тест | `gpt-6-luna` |
| Один стратегический этап Deep Strategy | `gpt-6-astra` |

Astra вызывается только для strategy/career в режиме Deep Strategy. Причина сохраняется в `astra_reason`. Каждая временная роль имеет явный input, критерий готовности из задачи, ожидаемый текстовый файл и максимум один проход. Бесконечных циклов ролей нет.

По умолчанию: $2 в день, $0.35 на запуск, reasoning medium, web search OFF. Это изменяемые параметры, а не подписка или обещание фиксированной цены. API-тест использует low и максимум 256 output tokens.

Перед вызовом резервируется консервативная оценка входа и максимального выхода. Токены reasoning входят в output usage. Необязательные роли пропускаются, если не хватает бюджета. Основной этап без бюджета не запускается; задача остаётся ready. После сетевого обрыва стоимость неизвестна, поэтому резерв не обнуляется. COSTS позволяет вручную сверить его с Usage OpenAI, записав сумму и основание.

Для web search размер добавленного внешнего контекста заранее неизвестен: резервируется полный context limit модели, с учётом длинного контекста и одного tool call. Поэтому при небольшом бюджете web-роль пропускается, сохраняется исследовательский план без заявлений о проверенных внешних фактах. Включение web search не гарантирует его выполнение при текущем лимите.

Цены вынесены в `core/config.py` / Settings и проверены 30.09.2026 по индивидуальным официальным страницам моделей:

- [GPT-6 Sol](https://developers.openai.com/api/docs/models/gpt-6-sol)
- [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)
- [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra)
- [Web search / pricing](https://developers.openai.com/api/docs/pricing)

Оценка может отличаться от биллинга из-за изменения тарифов, особенностей тарифа аккаунта и cache write usage. Если фактическая оценка превысит резерв, Ангелис записывает предупреждение и останавливает дальнейшую автономную работу.

## Расписание независимо от открытой вкладки

**По умолчанию выключено.** Streamlit служит интерфейсом; GitHub Actions выполняет плановые задания, даже когда браузер закрыт и ПК выключен. Не запускай бесконечный цикл или cron внутри Streamlit Community Cloud.

Для включения позже:

1. Файл `.github/workflows/viktor-mir-angelis.yml` находится в ветке `main` отдельного репозитория Ангелис.
2. GitHub → репозиторий → **Settings → Secrets and variables → Actions**: добавь secret `OPENAI_API_KEY`; variable `ANGELIS_WORKER_ENABLED` = `true`. Для GitHub Actions отдельный PAT не нужен: используется встроенный `GITHUB_TOKEN` с Contents write.
3. В Ангелис → SETTINGS включи **Scheduler ON** и **Разрешить автономную работу**, задай времена и сохрани.

Оба переключателя и переменная нужны намеренно: публикация кода сама по себе не включает расходы. Времена по умолчанию: 08:00 обзор, 09:00 BACKLOG, 21:00 отчёт, 23:00 обслуживание, Europe/Moscow. Actions проверяет план на 17-й минуте каждого часа. Поэтому задача 09:00 обычно начнётся около 09:17, иногда позже. Пропуски старше двух часов не воспроизводятся массово. Одно задание запускается максимум раз в сутки.

**Pause All Autonomous Work** сохраняет паузу и запрашивает остановку текущего цикла. Уже отправленный API-запрос может завершиться и стоить денег; следующие вызовы не запускаются. Незавершённый запуск после истечения 10-минутной lease становится interrupted и сохраняет резерв неопределённых расходов.

GitHub Actions допускает задержки и пропуски расписания; это не гарантированный постоянно работающий сервер. Для строгого 24/7 в будущей версии нужен отдельный worker на сервере. [Официальные ограничения GitHub Actions](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule). Streamlit не гарантирует сохранность локальных файлов: [официальная документация](https://docs.streamlit.io/develop/concepts/connections/connecting-to-data).

## Необязательный запуск на Windows

Python 3.12. PowerShell, из корня репозитория:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
$env:ANGELIS_STORAGE = "local"
.\.venv\Scripts\python.exe cli.py init
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Активация PowerShell окружения не нужна. Для реального API создай `.streamlit/secrets.toml` по примеру; для локального режима оставь `ANGELIS_STORAGE = "local"`. Хранение локального режима — папка `data/`, её нужно копировать для резервной копии. Этот режим не обеспечивает доступ через интернет сам по себе.

Проверки и отдельный цикл:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe cli.py run --dry
.\.venv\Scripts\python.exe cli.py run --mock
```

`--mock` создаёт явно помеченные синтетические данные для проверки. Пользовательский интерфейс никогда не подменяет реальную модель mock-ответами. Для платного CLI-запуска задай `OPENAI_API_KEY` через переменную среды, затем `python cli.py run`. `init` не перезаписывает уже существующую память.

## Проверено и ограничения

Проверено автоматическими тестами: CSV с BOM/кавычками/переносами, STATE, безопасные пути, artifacts, журнал, модельный routing, бюджет до API, неопределённая стоимость, остановка, recovery, зависимости, окно расписания, local restart, atomic Git commits при конкурентном изменении, все страницы Streamlit, пароль до доступа к данным, полный mocked цикл.

Адаптированная приёмка исходного задания (Streamlit вместо Next.js):

| № | Условие | Проверка |
| --- | --- | --- |
| 1 | Чистая установка Windows | Не проверено на Windows |
| 2 | Установка зависимостей | Пройдено в чистом Linux venv |
| 3 | Реальные Secrets в Streamlit Cloud | Требует подключения владельцем |
| 4 | API key и доступ к моделям | Реальный запрос не проверен |
| 5 | Запуск приложения | Проверен Streamlit AppTest |
| 6 | TODAY показывает seed | Пройдено |
| 7 | Dry Run показывает журнал | Пройдено |
| 8 | Реальный LLM cycle | Не проверен без ключа |
| 9 | Создан Markdown artifact | Пройдено на mock |
| 10 | STATE/BACKLOG безопасно обновляются | Пройдено на mock и Git API fixture |
| 11 | Journal содержит полный цикл | Пройдено на mock |
| 12 | Costs показывает model/tokens/cost | Пройдено на mock |
| 13 | Restart | Пройдено local |
| 14 | Память, artifacts и журнал сохраняются | Пройдено local; Git commit проверен fixture |

**10/14 проверено в доступной среде.** Это не заявление о выполненной Windows/Cloud/real-API приёмке. При подключении Streamlit останется пройти четыре отмеченных условия.

Хранилище v0.1 ограничено 9 МБ текущего JSON-снимка. Это решение для небольшого личного текстового MVP; большого архива и загрузки изображений здесь нет. Для масштабирования предусмотрена миграция в базу данных. Файлы не удаляются автоматически.
